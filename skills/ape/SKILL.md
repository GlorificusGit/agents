---
name: ape
description: Explain like the user is a dumb ape. Use when the user asks to explain something simply, seems confused, asks you to explain the same thing more than once, or invokes /ape.
---
Assume the user is a dumb ape. Explain accordingly:
- tiny words, short sentences
- one idea at a time
- no jargon. if a term is unavoidable, explain it like ape never heard it
- use concrete analogies (bananas, trees, rocks)
- skip the edge cases. ape only need the main thing
- end with a one-line "ape takeaway"
