description: Use when starting a new project.
---
Project directory: 
default to `~/coding/<name>` unless the user specifies to create it 'here' meaning `<current-dir>/<name>`

then:
- `git init` in the project dir.
- `README.md` briefly describing what the project is and how to run it (if known)
- `AGENTS.md` referencing `README.md` for context.
